# AutoLog

<img src="apk/app-icon-512.png" width="88" alt="AutoLog 계기판 바늘 아이콘">

**차가 쓰고, 한마디로 끝내는 업무용승용차 운행일지.**

AutoLog는 Pleos Connect 차량의 계기판 주행거리와 시각을 자동으로 기록하고, 도착 후 운전자에게 운행 용도만 확인하는 서비스입니다. 회사 관리자는 웹 대시보드에서 기록을 모아 보고 업무사용비율을 확인한 뒤 운행기록부를 내려받을 수 있습니다.

## 어떤 불편을 줄이나요?

운전자는 매번 출발·도착 시각과 계기판 거리를 적어야 하고, 관리자는 여러 차량의 기록을 모아 정리해야 합니다. AutoLog는 차량이 아는 정보는 자동으로 채우고, 사람의 판단이 필요한 **출퇴근·업무·개인 여부**만 확인해 기록 누락과 반복 입력을 줄입니다.

## 이용 흐름

1. **차량 연결** — 관리자가 대시보드에 차량·직원을 등록하고, 차량 앱에 표시된 6자리 코드로 연결합니다.
2. **자동 기록과 용도 확인** — 운전자를 선택하고 동의하면 기어·계기판 변화로 운행을 기록합니다. 주차 후 음성이나 화면으로 용도를 고릅니다. 답하지 못한 운행은 미확인으로 남겨 나중에 정리할 수 있습니다.
3. **회사에서 확인·내보내기** — 기록이 서버로 동기화되면 관리자가 차량·기간·직원·용도별로 조회하고, 월간 집계와 XLSX 운행기록부를 확인합니다.

## 주요 기능

| 차량에서 | 관리자 대시보드에서 |
| --- | --- |
| 계기판 거리·시각 기반 자동 운행 기록 | 차량별 주행거리·업무사용비율 집계 |
| 등록 장소와 시간대에 따른 용도 추정 | 미확인 운행·동기화 지연 등 확인 |
| 도착 시 음성·화면 확인, 미확인 운행 정리 | 운행 조회·용도 수정과 수정 이력 확인 |
| 통신이 끊겨도 로컬 저장, 이후 동기화 | 차량·직원·회사·거래처 관리 |
| 이번 달 운행 CSV 저장 | 차량별·기간별 운행기록부 XLSX 다운로드 |

## 기록의 신뢰성과 개인정보

- 차량이 기록한 시각·계기판 값은 서버 전송 후 수정할 수 없습니다. 용도 등 수정 가능한 항목의 변경은 이력으로 남깁니다.
- 주행 좌표와 집 위치는 서버로 보내지 않습니다. 서버에는 출발·도착 장소의 유형과 이름만 전달합니다.
- 개인 운행의 장소·세부 시각·메모는 관리자에게 공개하지 않으며, 관리자가 개인 운행을 다른 용도로 바꿀 수도 없습니다.
- 미확인 운행은 집·미등록 장소와 세부 시각을 가립니다. 관리자가 출퇴근·업무로 확정하면 사유와 이력이 남습니다.

## 서비스 체험과 검증

**[관리자 대시보드 열기](https://autolog.aihub.io.kr)** · **[시연 영상 보기](https://youtu.be/Z5fA_ZXDCBs)**

제출용 차량 앱은 **[AutoLog_release.apk](apk/AutoLog_release.apk)**(v0.1.0)입니다. Pleos Connect 전용 에뮬레이터·호환 차량에서 설치하고, 대시보드의 차량 관리에서 앱의 6자리 코드로 연결합니다. 주차 후 3분이 지나면 운행 용도를 확인합니다. 체험 로그인 정보는 대회 제출 문서에서 안내합니다.

```sh
adb install "apk/AutoLog_release.apk"
```

Pleos Connect Emulator와 배포 서버를 연결해 신규 차량 등록부터 기록 전송까지 검증했습니다. 운행 **5건·34.5km**의 앱·서버 식별자와 거리가 일치했고, 용도 수정 동기화·개인 운행 비공개 처리·CSV/XLSX 저장도 확인했습니다. 서명된 release에서도 신규 연결·P 유지 180초·1km 운행 전송을 추가 확인했습니다.

음성 검증은 PCM 입력으로 수행했으며 실제 마이크 입력은 별도 확인이 필요합니다. 자세한 확인 범위와 에뮬레이터 제약은 [검증 결과](docs/contracts/validation.md)에 정리했습니다.
